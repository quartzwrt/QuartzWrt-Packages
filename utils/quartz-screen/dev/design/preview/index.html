QuartzWrt 小屏 · UI 方向 A/A+ 预览（R2 · 已实现）

320×172 实尺寸；1× 就是实屏像素，3× 用于看细节。数据为样例。已按此稿落地 A+（实机渲染见 dev/mockups）。

页点：默认 4 页（概览/网络/蜂窝/系统）；可选页（无线/时钟/便签）加入后按 7 页显示。

A / A+ 规则

  • 顶栏 22px：标题左、页点中、时间右；页点从底部移走。
  • 3 个主数值格：标签 10px、主数值 28px；主信号用大小/颜色主导。
  • A 极简：3 格 + 单行底栏；A+ 增强：格内补充行 + 9–11px 次要行（默认）。
  • 已移除网络/蜂窝折线图：网络换 Top 3 流量设备；蜂窝换模组详情。
  • 运营商图标复用 Dashboard 官方符号（移动/联通/电信），屏上栅格化为小图标。
  • 依旧无渐变/装饰动画/1px 描边；彩色只给状态与主数值；9px 数据行用 text2 保证对比度。

本轮改动

  • 概览：CPU 1.3GHz / 内存 1.6·4.0GB / 负载 + 在线数 + WAN 协议。
  • 网络：Top 3 设备流量条（bandix.top；无 bandix 时回退 WAN 详情）。
  • 蜂窝：运营商图标 + 频段/带宽/PCI/温度/ARFCN/SIM 六项。
  • 系统：启动时间 / 5+15 负载 / 根分区用量 + CPU/内存/温度/进程。
  • 无线：加密方式、AP 模式、radio、HT、客户端列表。

已确认 / 实现

  • A+ 为实机版；A 仅保留预览对照。
  • 网络 Top 3 已实现（无 bandix 回退 WAN 接口详情）。
  • 蜂窝 6 项已实现；USB 速率不在快照，改用 ARFCN。
  • 无线首格为「在线设备」总数（非严格 WiFi 关联）；列表 2 条。
  • 速率移到底行第二行右侧，避免第一行被截断。
  • 浅色/英文随渲染器自动可用。
